# Política de privacidad de Bonfer

Página estática con la política de privacidad de la app Bonfer (Bonfer Tech SL), publicada con GitHub Pages:

https://bonferinfo.github.io/politica-privacidad-bonfer/

- Todo está en `index.html` (HTML y CSS en línea, sin compilación).
- Para cambiarla, edita `index.html`, actualiza la fecha de «Última actualización» y haz push a `main`. GitHub Pages la publica en un par de minutos.
- Pendiente: rellenar `[NIF pendiente]` y `[Domicilio pendiente]` y pasar la revisión legal (quitar entonces el aviso de versión provisional).

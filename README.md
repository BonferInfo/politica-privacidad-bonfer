# Política de privacidad de Bonfer

Páginas estáticas de la app Bonfer (Bonfer Tech SL), publicadas con GitHub Pages:

- Política de privacidad: https://bonferinfo.github.io/politica-privacidad-bonfer/ (`index.html`). Es la que enlaza la app (`PRIVACY_POLICY_URL`).
- Borrar la cuenta y los datos, que pide Google Play: https://bonferinfo.github.io/politica-privacidad-bonfer/borrar-cuenta/ (`borrar-cuenta/index.html`).

Cada página lleva su HTML y su CSS dentro, sin nada que compilar.

- Para cambiarlas, edita el `index.html` que toque, actualiza la fecha de «Última actualización» y haz push a `main`. GitHub Pages las publica en un par de minutos.
- El texto es el mismo que el de `../webs-apps/bonfer/contenido/` (`privacidad.html` y `borrar-cuenta.html`). Si cambias uno, cambia el otro.
- Pendiente: pasar la revisión legal y quitar entonces el aviso de «Versión provisional».
